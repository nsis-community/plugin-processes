This repository mirrors the Processes plug-in, which was previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/). Its source has been rearranged so that it builds automatically; code changes are limited to build fixes.

**Are you the author?** You're welcome to take it over: [open an issue](https://github.com/nsis-community/plugin-processes/issues/new) and we'll transfer the repository to you.

## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-processes/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `Processes.dll` to `Plugins/<variant>/`.
